## Caveats

1. **NOT a paper task**. TIGER paper (Su et al. AAAI 2024) does binary
   classification only. This multi-class variant is the project
   extension; no paper number to compare to. Cross-baseline comparison
   (vs HDN-DDI-mcc / EmerGNN-mcc / etc.) is the meaningful reference.

2. **152 classes from project data ≠ paper's 86 DrugBank DDI types.**
   The project's relation schema is more granular. Numbers are not
   directly comparable to TIGER-DW from any other study using the
   strict DrugBank-86 setup.

3. **macro F1 is dominated by long-tail classes** with few positive
   examples. Top-k acc and macro AUC are more stable indicators here.

4. **Cold-start patch off**, single seed (same caveats as binary
   variant — see `2026-05-19__binary_seed42_e50.md`).
