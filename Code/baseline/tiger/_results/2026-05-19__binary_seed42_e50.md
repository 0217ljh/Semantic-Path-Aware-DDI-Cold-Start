## Trajectory across cold-start levels

```
S0 AUC=0.864 → S1 AUC=0.712 → S2 AUC=0.584
              (-0.152)         (-0.128)
```

Expected pattern: AUC monotonically decreases as drug-overlap with
train shrinks. S2 close-to-random (0.584 vs 0.5 chance) is consistent
with the `cold_start_patch=False` configuration — unseen drugs on the
BKG channel get the default zero-row center-node embedding so the model
can only score via the MG (molecular) channel.

## Caveats

1. **No paper number to compare to**. TIGER paper (Su et al. AAAI 2024)
   doesn't publish cold-start (S1/S2) results — paper's 5-fold CV is
   random shuffle over DDI pairs (= our S0-equivalent). For S0, the
   reproduction-side achieved AUC=0.8625 ± 0.0061 (5-fold mean ± std,
   TIGER-KS extractor) on DrugBank vs paper's 0.8642 ± 0.0065 (within
   1σ). Our **S0 AUC=0.8642 here** is point-identical to paper mean,
   though on different data (project's 800-drug merged KG vs paper's
   DrugBank-only 1052-drug graph).

2. **Cold-start patch was OFF** (paper-faithful default). Codex round-1
   review (`_reviews/2026-05-18__baseline.md` §"project-extension")
   recommended enabling `--tiger-cold-start-patch` for S1/S2 cold-start
   runs. A follow-up run with the patch ON would show the value of
   that project extension on S2 in particular.

3. **Single seed** (42). Multi-seed mean ± std would give statistical
   stability indicators; deferred to follow-up.

4. **Extractor = randomWalk** (TIGER-DW). The reproduction-side PASS
   evidence used `khop-subtree` (TIGER-KS). Both are paper-valid
   choices. `khop-subtree` reportedly slightly stronger on dense
   datasets per paper Sec "Effects of Subgraph Extractors".

## Reproducing this result

```bash
python Code/scripts/run_baseline.py \
    --baseline tiger \
    --kg-source merged \
    --epochs 50 \
    --tag tiger_binary_e50_seed42
```

Approximate wall time: ~7 h on RTX 5090. First run additionally pays
the cache-build cost (~5-10 min for `mol_pkl` + `bkg_cache` +
`subgraph_cache` via subprocess builders per
`baseline/tiger/_shared.py`); subsequent runs hit cache.
