## 3. Paper core contributions verification (contribution-first per CLAUDE.md)

Paper 3-5 core contributions (extracted from abstract + intro):

1. **Path-based pairwise drug representation** — learn flow-based GNN on
   the *L-hop subgraph between two drug nodes*, not on single nodes
2. **Bidirectional propagation** — forward edges (h, t, r+n_rel) + reverse
   edges (t, h, r) + self-loop (e, e, 2*n_rel) for each entity
3. **Attention-weighted relation aggregation** — per-edge attention over
   relation embeddings, RESCAL-like output head
4. **Inductive simulation via `shuffle_train`** — per-epoch random 80/20
   split of train DDI into "fact" (added to KG) vs "target" (prediction
   labels) to simulate cold-start emerging drugs

For `multi_cls/baseline.py` (registered `"emergnn_mc"`):

| # | Contribution | Implementation | Verified |

| 3 | attention-weighted relation | `model.py:_chunk_compute_and_scatter` per-relation Wr | ✅ |

## 6. Migration / Fixes history (this round, 4 codex rounds)

### Round 1 — Initial gap analysis (codex)
Codex flagged 5 CRITICAL/MEDIUM gaps after the initial port from
reproduction:
- ❌ CRITICAL: `shuffle_train` completely missing → training degenerated
  to transductive (always sees all train DDI as KG facts)
- ❌ CRITICAL: save() persists `_n_base_rel` but model was built with
  expanded `_n_base_rel_with_ddi` → load_state_dict would shape-mismatch
- ❌ CRITICAL: `_eval_edges` (paper's vKG = train_ddi + base_kg) not
  persisted → predict_proba after load fell back to base-KG only
- ❌ MEDIUM: binary BCE used default `reduction='mean'` → effective lr
  shrunk by batch_size factor vs paper's `loss.sum()`
- ❌ MEDIUM: `ReduceLROnPlateau(patience=10)` stepped every epoch — paper
  steps every `epoch_per_test=5` epochs so effective tolerance = 50 raw
  epochs, not 10

### Round 2 — Fixes landed
| Fix | File:line |
|---|---|
| `shuffle_utils.py` NEW: ports paper `data_loader.shuffle_train` + `build_edge_lists_from_triplets` | `shuffle_utils.py:27-128, 131-158` |
| `shuffle_train` called per epoch in fit() | `binary_cls/baseline.py:419`, `multi_cls/baseline.py:289` |
| `n_base_rel_with_ddi` saved + loaded | `binary_cls/baseline.py:577, 654`, `multi_cls/baseline.py:428, 504` |
