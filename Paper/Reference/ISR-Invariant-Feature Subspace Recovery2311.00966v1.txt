## TL;DR
Extends the provable invariant-feature-subspace-recovery framework from binary classification to MULTI-CLASS classification (ISR-Multiclass, environment complexity ceil(d_s/k)+1) and to REGRESSION (ISR-Regression under a causal z_c->y model, E>=d_s+1), showing the number of classes can trade off against the number of environments, all via moment statistics + eigen/SVD, optimization-free with global convergence.

## Problem & Contributions (new relative to 2201)
- Q1 answered: In linear causal models, can the number of CLASSES compensate for the number of ENVIRONMENTS in recovering invariant features? YES — ISR-Multiclass needs only ceil(d_s/k)+1 environments (Sec 4.2, Theorem 3).
- Q2 answered: Can we provably recover the invariant subspace for CONTINUOUS targets (regression)? YES — ISR-Regression, E>=d_s+1, under a new causal model (Sec 4.3, Theorem 4).
- Removes the binary-symmetry assumption on conditional feature means used in the original ISR-Mean.
- Broader empirical validation: Colored MNIST (multi-class), tabular data, regression benchmark; more baselines.

## Method / Core mechanism (NEW parts only)
- ISR-Multiclass (Algorithm 3, Sec 4.2, pages 15-17): (I) estimate class- AND environment-conditional sample means x_ek = A mu_k + B mu_ke; build one matrix M_k (E x d) per class k. (II) PCA each M_k; take the E-1 eigenvectors of NON-zero eigenvalues -> P_k (recovers the per-class spurious directions). (III) stack all P_k into M_total = [P_1 | ... | P_k] in R^{d x (E-1)k} (motivated by flag-mean). (IV) SVD of M_total: the top d_s singular vectors recover the COMMON spurious subspace (Theorem 3, Eq. 28). (V) train classifier in the NULL SPACE of the recovered spurious subspace = the invariant subspace. Key counting argument: need (E-1)k >= d_s, giving E >= ceil(d_s/k)+1.
- ISR-Regression (Algorithm 4, Sec 4.3, pages 18-19): NEW causal model (Fig. 2) where invariant z_c causally determines y (y independent of spurious z_e given z_c). Algorithm = "ISR-Mean applied over the ENTIRE dataset" (global input means per environment, not class-conditioned): (I) per-environment global sample mean x_e = A mu_c + B mu_e, stack into M (E x d). (II) PCA. (III) take the d_s HIGHEST-eigenvalue eigenvectors as the spurious subspace P'', then its null space P' is the invariant subspace. (IV) fit ERM predictor on x -> P' x. Environment complexity E >= d_s+1 (Theorem 4).

## Key results & numbers (NEW parts; with pointers)
- Multi-Class Colored MNIST (MC-CMNIST, 10-class, Sec 5.2.2, Table 4): ISR-Multiclass as post-processing improves both average and worst-group / worst-10-group accuracy, especially over ERM and IB-ERM; variance of worst-group accuracy is high (noted by authors). Baselines include ERM, IRM, IB-ERM, IB-IRM (Arjovsky et al. 2019; Ahuja et al. 2021a).
- Synthetic regression benchmark (Sec 5.3.2, Table ~5, page ~44): ISR-Regression post-processing evaluated by worst-group RMSE against ERM, IRM, MixUp, C-MixUp (Yao et al. 2022); environment defined by binning red-pixel values.
- Real datasets (Waterbirds/CelebA/MultiNLI, Table 1; CLIP ViT-B/32 Waterbirds, Table 3; partial env labels, Fig. 6): SAME headline results as the 2201 version (e.g. Waterbirds/ERM worst-group 62.93 -> 76.10 ISR-Mean -> 82.46 ISR-Cov). Now reported alongside additional post-processing baselines.
- Synthetic Linear Unit-Tests (Sec 5.1): unchanged validation of Theorems 1 and 2 environment complexities.

The ISR-Multiclass "classes compensate for environments" result is a nice rhetorical parallel to our "shared typed mediators let unseen drugs reuse a small set of interaction bases," but note it is a DIFFERENT mechanism.

## Safe-to-cite claims (with section pointers)
- ISR-Multiclass: k-class classification lowers environment complexity to ceil(d_s/k)+1; classes trade off against environments by factor 1/k (Theorem 3, Sec 4.2).
- ISR-Regression: provable invariant-subspace recovery for continuous targets under the causal z_c->y model, E>=d_s+1 (Theorem 4, Sec 4.3; Fig. 2).
- Summary of all four algorithms and complexities: Table 1 (page 2) — ISR-Mean O(d_s)/Thm1, ISR-Cov O(1)/Thm2, ISR-Multiclass O(d_s/k)/Thm3, ISR-Regression O(d_s)/Thm4.
- All four are optimization-free (ERM + eigen/SVD) with global convergence (Sec 4.2 "Global Convergence"; Sec 4.3).
- ISR usable as post-processing on frozen black-box features to raise worst-group accuracy across ERM/IRM/IB-IRM/MixUp/GroupDRO (Sec 5.2, Tables 1,3,4).

## Do-NOT-overclaim / caveats
- Guarantees are for LINEAR causal/Gaussian data models in the infinite-sample limit; on real non-linear data ISR is a heuristic post-processing layer with no guarantee (authors note high worst-group variance on MC-CMNIST, Table 4 caption).
- ISR-Regression uses a DIFFERENT (causal z_c->y) data model than the classification algorithms (anti-causal y->z_c). Do not merge the two settings when citing.
- "Low-rank / low-dimensional" = an invariant feature SUBSPACE of dimension d_c, recovered by (near-)zero-eigenvalue directions or by null space of the spurious subspace. This is NOT a low-rank factorization of a task-adaptation residual (that is Stream B / our M_A M_B). Keep the two notions distinct.
- The multi-class result does not eliminate the need for environments; it reduces the count. Requires knowing/estimating d_s and k. Not directly applicable to single-domain, environment-less endogenous entity-support shift without substantial reframing.
