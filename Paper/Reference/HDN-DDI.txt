Title: HDN-DDI: a novel framework for predicting drug-drug interactions using hierarchical molecular graphs and enhanced dual-view representation learning
Authors: Jinchen Sun, Haoran Zheng
Venue+Year: BMC Bioinformatics, 26:28, 2025
arXiv-or-DOI: https://doi.org/10.1186/s12859-025-06052-0
PDF filename: HDN-DDI.pdf

## TL;DR
A molecular-structure DDI method that decomposes each drug with a refined BRICS algorithm into
real chemical substructures, builds an "atomic-substructure-molecular" hierarchical molecular
graph, and encodes it with stacked GAT-based HDN Blocks combining a within-molecule
(hierarchical) view and a between-drug (interactive) view over substructure-level nodes. A
co-attention decoder aggregates multi-depth global representations for a relation-typed bilinear
DDI score. Molecular-graph only, no KG. Evaluated in both warm-start and cold-start settings.
(Abstract; Method; Fig 1)

## Problem & Contributions
- Problem: binary-style DDI triple prediction f: D x R x D -> [0,1], output 1 if (Dx, r, Dy)
  interaction exists (Method, "Problem definition", page 3).
- Motivation: substructure-based methods are strong but suffer (i) poor interpretability of
  learned substructures (mismatch with medicinal-chemistry substructures) and (ii) isolation of
  chemical substructures (BRICS-fragment methods like PMSE-DDI keep fragments disconnected from
  local/global molecular context) (Introduction, page 2).
- Contributions (Introduction, page 3): (1) explainable substructure extraction module using an
  interpretable chemical decomposition (refined BRICS); (2) hierarchical molecular graph that
  integrates atom / substructure / molecule levels; (3) enhanced dual-view representation learning
  focusing on key substructures.

## Method / Core mechanism (equations in words + notation)
- Input: molecular graph G=(V,E), atom node feature x in R^66 (details in Additional file 1)
  (Input, page 3).
- Substructure extraction (Fig 2, pages 5-6): SMILES -> RDKit graph -> BRICS fragmentation
  (ref [30]) + refined ring-splitting rules from HiMol/Zang et al. [29]. Build hierarchical graph
  by adding substructure-level nodes (bidirectional edges to their constituent atoms) and one
  molecular-level node (bidirectional edges to all substructure nodes). Original atom-atom bond
  edges retained; NO edges between substructure-level nodes within a molecule.
- HDN Encoder = stack of HDN Blocks; each block has three parts (HDN encoder, pages 6-8):
  1. Hierarchical-view layer: single-layer GAT over the full hierarchical graph; node update
     h_i^(l+1) = sigma( sum_{j in Ni∪{i}} alpha_ij W h_j^(l) + b ), attention alpha_ij from
     LeakyReLU on concatenated transformed features (Eqs 1-3). Nodes aggregate across levels.
  2. Interactive-view layer: bipartite graph G~ = V_s^(x) x V_s^(y) between the two drugs'
     substructure-level nodes ONLY (atoms excluded, to reduce noise). Single-layer GAT with
     separate weights; connections randomly dropped during encoding (since DDIs arise from a few
     key substructures) (Eqs 4-6). Atom/molecule nodes get a shared-weight nonlinear transform (Eq 7).
  3. Update layer: fuse hierarchical h_i^(l+1) and interaction h~_i^(l+1) via ELU(MLP([. || .]))
     (Eq 8), then one more GAT over the whole graph; output feeds next block. Global drug
     representation read directly from the molecular-level node g_x^(l+1)=h_{x_mol}^(l+1) (Eq 9),
     avoiding extra pooling.
- HDN Decoder (co-attention, pages 8-9): layer-wise association gamma_{ll'} = alpha^T tanh(
  Wx g_x^(l) + Wy g_y^(l') ) (Eq 10). Final score s(Dx,r,Dy) = sigmoid( sum_l sum_l'
  gamma_{ll'} g_x^(l) Mr g_y^(l') ) with per-relation embedding matrix Mr in R^{d x d} (Eq 11).
- Loss: binary cross-entropy (Eq 12); negatives by replacing one drug of each positive triple.
- Params (page 10): 6 HDN Blocks; hierarchical/interactive views 64-dim, update layer 128-dim;
  2 attention heads; batch 512; lr 0.001.

## Key results & numbers (with Table/Fig/Section pointers)
- Datasets (Results/Datasets, page 9; Table 1 page 10): DrugBank 1706 drugs, 86 interaction
  types, 191,808 positive DDIs (warm split 6:2:2). Twosides 645 drugs, 963 interaction types,
  4,576,287 positive DDIs. Negatives generated by drug replacement. Cold-start uses DrugBank only.
- Warm-start (Table 2, page 12), 3-run average, %:
  DrugBank: HDN-DDI ACC 97.93, AUROC 99.73, AUPR 99.72, F1 98.03 (best; +0.99 ACC over SOTA).
  Twosides: HDN-DDI ACC 99.38, AUROC 99.97, AUPR 99.97, F1 99.38 (best).
  Baselines incl. MHCADDI, SSI-DDI, GMPNN-CS, SA-DDI, DSN-DDI, BDN-DDI.
- Cold-start (Table 3, page 13), DrugBank, 3-run average, %:
  Ds1 (new<->new): HDN-DDI ACC 79.84, AUROC 89.48, AUPR 89.65, F1 77.42 (best; +4.96 ACC,
    +7.08 F1 over prior SOTA which was BDN-DDI ACC 74.88 / F1 70.21).
  Ds2 (new<->old): HDN-DDI ACC 89.43, AUROC 95.92, AUPR 95.95, F1 89.34 (best; +4.08 ACC, +5 F1).
  Note: abstract elsewhere says 79.84% and 89.43% ("4.96% and 4.08%") consistent with Table 3.
- Ablation (Table 4, page 13-14): removing substructure extraction (wo-SEM) causes the largest
  drop; enhanced dual-view (vs initial DSN-DDI-style) adds +3.69/+4.45 ACC on the two partitions;
  molecular-level-node global readout beats sum-pool and SAGPooling.
- Real-world (Fig 3, Additional file 3, pages 14-15): train on pre-2015 drugs (1585), test on
  >=2015 FDA-approved (121 drugs; 25,466 positive test tuples). HDN-DDI beats DSN-DDI/BDN-DDI by
  +5.86 ACC, +4.62 AUPR, +6.09 F1.
- Case study (Fig 4, pages 15-17): top-40% contribution substructures match known functional
  groups (nitroso, pyridine/amide, barbituric acid, beta-lactam ring, sulfonic acid group).

## Relevance to our cold-start low-rank DDI paper (§2.1 taxonomy slot; molecular vs KG; warm vs cold; how we'd cite)
- §2.1 taxonomy slot: MOLECULAR-substructure-based GNN (substructure interaction + dual-view).
  Uses drug MOLECULAR structure (SMILES -> BRICS substructures -> hierarchical graph); NO KG. The
  authors explicitly position molecular-graph methods as adapting to new drugs "without relying
  on external knowledge" (Introduction, page 2).
- Warm vs cold: warm-start AND cold-start capable; strong cold-start results and same S1/S2-style
  drug split (Ds1 both-new, Ds2 one-new) as our setting. Ds1 = both drugs unseen matches our
  strict cold-start.
- How we'd cite: (a) recent (2025) state-of-the-art molecular-substructure cold-start baseline in
  §2.1; (b) evidence that interpretable BRICS substructures + hierarchical + dual-view improve
  cold-start over SSI-DDI/DSN-DDI/BDN-DDI; (c) contrast point: it is molecular-only and treats DDI
  as substructure interaction, whereas our method adds KG/relational low-rank structure -- HDN-DDI
  shows how far pure-molecular can go on unseen drugs (Ds1 F1 77.42), a target to compare against.

## Do-NOT-overclaim / caveats
- Reported DrugBank stats: 1706 drugs, 86 types, 191,808 positive DDIs (page 9). This differs
  slightly from SSI-DDI's 1704/191,400; do not treat the numbers as identical.
- Cold-start uses DrugBank ONLY (not Twosides) "due to its larger number of drugs" (page 10).
- All improvements are relative to the paper's own baseline reimplementations under a shared
  split; numbers are DrugBank/Twosides binary-triple ACC/AUROC/AUPR/F1 with generated negatives,
  NOT the multi-class event-prediction metrics used by e.g. MRCGNN. Do not cross-compare numbers.
- Authors' stated limitations (Discussion, page 17): some molecules under-decompose; adding edge
  attributes HURT performance; DDIs also depend on metabolism/external knowledge not modeled.
- Cold-start reported over 3 runs (random 20% drugs new each run); Table 1 lists Fold 0/1/2 sizes.
  Table 3 values are 3-run averages (per project convention: say "3 runs," not seed numbers).
