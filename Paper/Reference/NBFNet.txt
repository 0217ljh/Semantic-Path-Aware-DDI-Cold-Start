Title: Neural Bellman-Ford Networks: A General Graph Neural Network Framework for Link Prediction
Authors: Zhaocheng Zhu, Zuobai Zhang, Louis-Pascal Xhonneux, Jian Tang (Mila - Quebec AI Institute; Universite de Montreal; HEC Montreal; CIFAR AI Chair)
Venue+Year: NeurIPS 2021 (35th Conference on Neural Information Processing Systems)
arXiv-or-DOI: NeurIPS 2021 proceedings; code at github.com/DeepGraphLearning/NBFNet (PDF gives no arXiv id on page 1; venue footnote confirms NeurIPS 2021)
PDF filename: NBFNet.pdf

## TL;DR
NBFNet is a path-based link-prediction GNN that represents a pair of nodes (u,v) for a query relation q as the generalized sum over all u->v paths of the generalized product of edge representations along each path. This path formulation is solved efficiently by the generalized Bellman-Ford algorithm, which NBFNet parameterizes with three learned neural operators (INDICATOR = boundary condition, MESSAGE = generalized multiplication, AGGREGATE = generalized summation). Because pair representations are built from source-conditioned message passing over structure/paths (edge reps are functions of the query relation, NOT learned per-entity embeddings), NBFNet works in both transductive and inductive settings and sets SOTA in both, while keeping low amortized per-triplet cost (Abstract; Sec 3; Tables 3-5).

## Problem & Contributions
Problem: Traditional path-based link predictors (Katz index, Personalized PageRank, graph distance) are inductive, interpretable, and scalable but use handcrafted metrics; embedding methods (TransE, DistMult, RotatE) have high capacity but are transductive and non-interpretable; subgraph-GNN methods (SEAL, GraIL) are inductive and powerful but materialize a subgraph per link and do not scale (Sec 1-2; Table 1). The paper asks for a method that has all four: inductive generalization, interpretability, high capacity, and scalability.
Contributions (Sec 1, 3):
1. A general path formulation for link prediction: pair representation = generalized sum over paths of generalized product of edge representations (Eqs 1-2). Katz index, Personalized PageRank, graph distance, widest path, and most reliable path are all special cases with specific (sum, product) operator choices (Theorems 1-5; Table 2).
2. Shows the formulation is solvable by the generalized Bellman-Ford algorithm under a semiring assumption (Eqs 3-4; Theorem 6), giving polynomial cost instead of enumerating exponentially many paths.
3. NBFNet: neural parameterization of that algorithm via learned INDICATOR / MESSAGE / AGGREGATE operators (Algorithm 1; Eqs 5-6), recovering NeuralLP / DRUM as special cases (Table 2) and generalizing to multi-relational KGs and homogeneous graphs, both transductive and inductive.
4. SOTA results with low amortized per-triplet time complexity and fewer parameters, plus path-based interpretability of predictions (Sec 4).

## Method / Core mechanism (equations in words + notation)
Path formulation (Sec 3.1): For query relation q, head u, tail v, the pair representation h_q(u,v) = generalized-sum (operator ⊕) over all paths P in P_uv of the path representation h_q(P) (Eq 1). Each path representation = generalized-product (operator ⊗, order-preserving, not required commutative) of the edge representations w_q(e_i) along the path (Eq 2). Different choices of ⊕/⊗ recover classic heuristics (Theorems 1-5; Table 2): e.g. Katz (⊕=+, ⊗=×), graph distance (⊕=min, ⊗=+), widest path (⊕=max, ⊗=min).
Generalized Bellman-Ford (Sec 3.1, Eqs 3-4): Assuming ⟨⊕,⊗⟩ form a semiring with identities, the pair rep is computed by a boundary condition h^(0)_q(u,v) = 1_q(u=v) (Eq 3) and the iteration h^(t)_q(u,v) = ( ⊕ over incoming edges (x,r,v) of [ h^(t-1)_q(u,x) ⊗ w_q(x,r,v) ] ) ⊕ h^(0)_q(u,v) (Eq 4). u and q are fixed, so the algorithm computes h_q(u,v) for ALL v in parallel; the distributive property avoids path enumeration. With ⊕=min, ⊗=+ it reduces to the classic Bellman-Ford shortest path (Sec 3.1).
Neural parameterization (Sec 3.2; Algorithm 1; Eqs 5-6): Relax the semiring assumption and replace the three operators with learned neural functions:
  - INDICATOR(u,v,q): boundary condition; sets h^(0)_v = 1(u=v)·q where q is a learned query embedding (a single query embedding worked better than also learning a 0-identity embedding).
  - MESSAGE(h^(t-1)_x, w_q(x,r,v)): replaces ⊗; instantiated using relational operators from KG embeddings — translation (TransE), scaling (DistMult), or rotation (RotatE).
  - AGGREGATE: permutation-invariant set operator replacing ⊕; sum / mean / max followed by linear + nonlinearity, or PNA (principal neighborhood aggregation).
Edge representations w_q(x,r,v) = W_r q + b_r are a linear function of the QUERY relation (simplified to b_r when few relations). Crucially, the authors note edge reps could instead use learnable ENTITY embeddings x,v, but "such a parameterization cannot solve the inductive setting" (Sec 3.2) — the inductive property comes precisely from NOT keying on entity identity. Different edge reps per iteration distinguish noncommutative paths (father's-mother vs mother's-father).
Interpretation: NBFNet is a source-specific message-passing GNN; every node learns a representation CONDITIONED on the source node u, and the pair rep is read out on target v — different from auto-encoder GNNs that compute h(u) and h(v) independently (Sec 3.2).
Link prediction: p(v|u,q) = sigmoid(f(h_q(u,v))), f a feed-forward net; heads predicted via inverse relation; negative log-likelihood loss with PCA negative sampling (Eqs 7-8; Sec 3.2).
Time complexity (Sec 3.2 "Time Complexity"; Table 1): O(|E|d + |V|d^2) per source-query group of |V| triplets, giving amortized O(|E|d/|V| + d^2) per triplet — same order as NeuralLP/DRUM and far below GraIL/SEAL's O(|E|d^2) per-link subgraph cost. Wall time on FB15k-237 test set: NBFNet 4.0 min vs GraIL ~1 month (estimated, downsampled) (Table 1).

## Key results & numbers (with Table/Fig/Section pointers)
- Knowledge graph completion, transductive (Table 3), FB15k-237 / WN18RR, filtered ranking:
  - FB15k-237: NBFNet MRR 0.415, H@1 0.321, H@3 0.454, H@10 0.599, MR 114 — best on all metrics. Best embedding baseline LowFER MRR 0.359; best path baseline DRUM MRR 0.343.
  - WN18RR: NBFNet MRR 0.551, H@1 0.497, H@3 0.573, H@10 0.666, MR 636 — best on all metrics.
  - Reported avg relative gains: +21% H@1 over best path method (DRUM), +18% H@1 over best embedding method (LowFER) (Sec 4.2). NBFNet uses far fewer parameters: 3M on FB15k-237 vs TransE 30M (Sec 4.2).
- Homogeneous graph link prediction (Table 4), Cora/Citeseer/PubMed, AUROC/AP: NBFNet best on Cora (0.956/0.962) and PubMed (0.983/0.982), competitive on Citeseer (0.923/0.936), WITHOUT using node features.
- Inductive relation prediction (Table 5), HITS@10, on GraIL's inductive splits v1-v4 of FB15k-237 and WN18RR:
  - NBFNet beats GraIL on ALL 8 splits. FB15k-237: v1 0.834 vs GraIL 0.642; v2 0.949 vs 0.818; v3 0.951 vs 0.828; v4 0.960 vs 0.893. WN18RR: v1 0.948 vs 0.825; v2 0.905 vs 0.787; v3 0.893 vs 0.584; v4 0.890 vs 0.734.
  - Reported avg relative gain +22% HITS@10 over GraIL (Abstract; Sec 4.2). Text notes GraIL can at most encode a ~2-hop subgraph while NBFNet efficiently explores longer paths (Sec 4.2).
- Ablations (Table 6, FB15k-237, MRR): (a) MESSAGE/AGGREGATE — advanced operators help (RotatE/DistMult > TransE; PNA > sum/mean/max); best DistMult&PNA / RotatE&PNA ~0.414-0.415. (b) Layers T: monotonic improvement up to 6 layers then saturates (0.345 at T=2, 0.415 at T=6, 0.416 at T=8) — no deep-GNN degradation. (c) By relation category: NBFNet improves both easy 1-to-1 and hard N-to-N cases over TransE/RotatE.
- Interpretability (Sec 4.4; Table 7): top-k path interpretations defined via partial derivative of prediction w.r.t. paths (Eq 9), approximated by edge importance and Bellman-Ford-style beam search; qualitative examples show soft logical entailment and analogical reasoning on FB15k-237.
- Config (Sec 4.1): 6 layers, 32 hidden units, 2-layer MLP (64) for f, edges directly connecting the query pair dropped during training, trained 20 epochs on 4 V100s.

## Relevance to our cold-start low-rank DDI paper (RW Para 1 premise; how we'd cite; the gap we build on)
NBFNet is the second anchor for Related Work Para 1 (inductive KG link prediction as the identity-free-reasoning premise). It is arguably the strongest single demonstration that PATH-based, source-conditioned reasoning — where edge representations depend only on the query relation and structure, explicitly NOT on learned per-entity embeddings — generalizes to unseen entities (SOTA on the inductive splits, Table 5) while remaining scalable. The paper states outright that keying edge reps on entity embeddings "cannot solve the inductive setting" (Sec 3.2), which is precisely the design principle our "drugs-as-selectors, no per-drug embedding" architecture inherits: transferable signal must come from the interaction/path structure, not from entity identity.
How we'd cite: In Para 1 we pair NBFNet with GraIL to establish that identity-free structural/path reasoning is feasible and state-of-the-art for generalizing to unseen entities, grounding the feasibility of our no-per-drug-embedding cold-start DDI design. NBFNet additionally lets us note this reasoning can be cast as a general (Bellman-Ford) path-aggregation operator, motivating our own path-aware treatment.
The gap we build on (our Para-1 turn): NBFNet shows identity-free path reasoning is feasible AND top-performing, but (i) even in its "inductive" setting the query is scored with a source-node boundary condition (INDICATOR seeds the SOURCE u), and its evaluation does not isolate the regime where BOTH endpoints of the target interaction are simultaneously unseen and only structure/paths between two novel endpoints remains — i.e. it does not ask which interaction structure stays transferable when neither endpoint has any prior signal; and (ii) it does not characterize the RANK / low-dimensional structure of that transferable cross-endpoint interaction signal. (Note: LowFER, a low-rank bilinear baseline, appears only as a competitor in Table 3 — NBFNet itself makes no low-rank characterization of the transferable signal.) Our paper takes up exactly this unasked question and characterizes its rank.

## Safe-to-cite claims (section pointers)
- NBFNet represents a node pair as a generalized sum over path products of edge representations, solved by the generalized Bellman-Ford algorithm (Eqs 1-4; Sec 3.1).
- The three learned operators INDICATOR / MESSAGE / AGGREGATE parameterize boundary condition / multiplication / summation (Sec 3.2; Algorithm 1).
- Edge representations are functions of the query relation, not entity embeddings; entity-embedding parameterization "cannot solve the inductive setting" (Sec 3.2) — this is the source of inductivity.
- Katz index, Personalized PageRank, graph distance, widest path, most reliable path, and NeuralLP/DRUM are special cases of the framework (Theorems 1-6; Table 2).
- SOTA on transductive KG completion (Table 3), homogeneous link prediction without node features (Table 4), and inductive relation prediction (Table 5); avg relative gains +18% H@1 vs best embedding, +21% H@1 vs best path method, +22% HITS@10 vs GraIL (Sec 4.2; Abstract).
- Amortized per-triplet complexity O(|E|d/|V| + d^2), far cheaper than subgraph GNNs GraIL/SEAL; wall time 4.0 min vs GraIL ~1 month on FB15k-237 (Table 1).
- Performance improves monotonically up to 6 layers with no deep-GNN degradation (Table 6b).
- Predictions are interpretable via top-k path attribution (Sec 4.4; Table 7; Eq 9).

## Do-NOT-overclaim / caveats
- NBFNet is NOT a DDI/drug method; KG datasets are FB15k-237 and WN18RR (generic), homogeneous datasets are citation graphs. Do not attribute any DDI or drug cold-start result to it.
- Its inductive evaluation uses GraIL's inductive splits (new test graph / unseen entities); the paper does NOT specifically isolate or name a "both interaction endpoints unseen, only structure remains" analysis, and does not study drug cold-start. Do not claim it addresses the both-drugs-unseen DDI regime.
- NBFNet makes NO low-rank characterization of the transferable interaction signal; LowFER (a low-rank bilinear method) is only a baseline in Table 3. Do not cite NBFNet as evidence of low-rank interaction structure — that framing is ours.
- Authors' stated limitations (Sec 5): the semiring assumption does not strictly hold once non-linear activations are used, so there is no theoretical guarantee on the relaxation; NBFNet is verified only on simple edge prediction, not complex logical (conjunctive/disjunctive) queries.
- Interpretability via Eq 9 is a first-order Taylor / edge-importance APPROXIMATION, not exact path attribution (Sec 4.4). Do not present it as exact.
- Numbers above are as printed in Tables 3-6; the paper reports single reported values per setting (no per-seed std in the main tables). State comparisons as reported, not as multi-seed significance.
- The PDF's page-1 header does not print an arXiv id; cite as NeurIPS 2021.
