# D. Biological Mechanism Examples (Narrative Grounding)

These examples ground the "drug interactions are class-level phenomena" claim. Use 2-3 in Intro, expand all 7 + bonus citation in Section 3.

## D.1 CYP2C subfamily (hepatic metabolism)

Warfarin metabolism via CYP2C9 with redundant CYP2C/CYP3A network. Amiodarone (inhibits CYP2C9 + CYP3A4) and fluconazole (inhibits CYP2C9 + CYP2C19 + CYP3A4) elevate S-warfarin exposure and bleeding risk **as class-level perturbations**, not single-isoform events.

Citation: **Agrawal et al. (2020), Clin Transl Sci** — PMC7485961

## D.2 Coagulation cascade

Warfarin + aspirin → 2-4× rise in major bleeding. Warfarin suppresses vitamin-K-dependent factors II, VII, IX, X (via VKORC1 + gamma-glutamyl carboxylase); aspirin acetylates platelet COX-1. Two different sub-networks of hemostasis converge as **class-level perturbation of clotting cascade**; no single protein explains the synergy.

Citation: **Hansen et al. (2010), Arch Intern Med** + **Dentali et al. (2007), Arch Intern Med** — PMID 22257078

## D.3 Renin-Angiotensin System (RAS)

ACE inhibitor (ramipril) + ARB (telmisartan) → increased hyperkalemia, AKI, hypotension without cardiovascular benefit (ONTARGET). Both block different RAS nodes (ACE vs AT1R). Toxicity emerges from **dual hit on entire RAS cassette**, not any single node.

Citation: **Mann et al. (2008), Lancet ONTARGET** + **Makani et al. (2013), BMJ meta-analysis**

## D.4 Adrenergic receptor system

Epinephrine + non-selective β-blocker (propranolol) → severe hypertension + reflex bradycardia. Propranolol blocks β1+β2 leaving α1-vasoconstriction unopposed. **Cardioselective β1-blockers (metoprolol) lack this effect**, proving the interaction is defined by which subset of the α/β receptor family is engaged.

Citation: **Foster & Aston (1983)** + **Pharmacy Times review (2009)**

## D.5 Serotonergic system

SSRI (sertraline) + triptan (sumatriptan) → serotonin syndrome (FDA black box). SSRIs raise synaptic 5-HT broadly; triptans are 5-HT1B/1D agonists. **Toxicity mediated by 5-HT2A and 5-HT1A, not the triptan targets directly** — class-level overflow of the serotonergic network.

Citation: **Gillman (2010), Headache** — doi 10.1111/j.1526-4610.2009.01575.x

## D.6 Dopaminergic system

L-DOPA + typical antipsychotic (haloperidol) → mutual antagonism. Haloperidol's D2 blockade reverses L-DOPA's motor benefit; L-DOPA re-triggers psychosis. **Quetiapine and clozapine** (weaker D2, with 5-HT2A) **are preferred**, proving the interaction depends on which dopamine receptor subtype family and pathway region is engaged.

Citation: **Friedman (2013), Lancet Neurol** + PMC4418258

## D.7 Cholinergic system

Donepezil (AChE inhibitor) + oxybutynin (non-selective M1/M3 antagonist) → erases cognitive benefit, raises dementia risk. **Darifenacin (M3-selective) and trospium (poor CNS penetration) are safer**, proving the effect depends on which muscarinic subtype family is blocked.

Citation: **Gill et al. (2005), Arch Intern Med** + **Bell et al. (2021), Pharmacol Res Perspect**

## D.8 BONUS — Strongest single citation for "DDI is class-level" thesis

**Hopkins, A. L. (2008). "Network pharmacology: the next paradigm in drug discovery." Nature Chemical Biology 4(11), 682-690.**

Hopkins explicitly argues that **drug action and drug-drug interactions are network-level phenomena, with phenotypic outcomes determined by perturbation of pathway modules and target families rather than a single protein**. This frames polypharmacology and DDI as a property of **mechanism classes** — the exact thesis our cold-start paper needs.

Complementary: **Berger & Iyengar (2009), "Network analyses in systems pharmacology", Bioinformatics 25(19), 2466-2472**.

# E. Molecular Fragment Extraction (verified survey)

Background research agent verified the fragment extraction methods used by major multi-modal DDI papers, evaluated pharmacology-grounded alternatives, and recommended a concrete pipeline.

## E.1 Survey of multi-modal DDI papers (what they do for SMILES → fragments)

| Paper | Method | Package | Pharmacology-grounded? |
|---|---|---|---|
| **MKG-FENN** (AAAI 2024) | 881-bit PubChem CACTVS fingerprint (binary presence of fixed dictionary) | PubChem precomputed | **No** — fixed dictionary, not a per-drug fragment graph |
| **TIGER** (AAAI 2024) | No explicit slice. Heterogeneous KG + atom-level molecular graph through relation-aware Transformer | DGL | **No** — implicit / learned |
| **SSI-DDI** (BIB 2021) | GAT receptive fields (l-th layer node = atom + 1..l-hop neighborhood) | RDKit + PyG | **No** — operational, tied to GNN depth |
| **DSN-DDI** (BIB 2023) | Dual-view GNN aggregations (intra + inter drug bipartite) | RDKit + PyTorch | **No** — learned |
| **MUFFIN** (Bioinformatics 2021) | Atom-level molecular graph, no fragment cut | RDKit + DGL | **No** — atom-level only |
| **MIRACLE** (WWW 2021) | Atom-level molecular graph, bond-aware MPN | RDKit + PyTorch | **No** — implicit |
| **HDN-DDI** (BMC Bioinformatics 2025) | **BRICS decomposition + ring split**, motif-level hierarchical graph | RDKit (`Chem.BRICS`) + PyTorch | **Yes** — BRICS is retrosynthetic and bioisostere-preserving |

**Strategic opportunity** ⭐: Only HDN-DDI uses chemistry-grounded BRICS. Everyone else uses fingerprints or learned receptive fields. **Our paper can claim chemistry-grounded fragment alignment as a clear differentiator**, especially since HDN-DDI uses BRICS for hierarchical encoding **not for mechanism alignment**.

## E.2 Pharmacology-grounded fragment methods (4 candidates)

| Method | What it captures | Pros for fragment ↔ mechanism alignment | Cons |
|---|---|---|---|
| **BRICS** (`rdkit.Chem.BRICS`) | Retrosynthetic cleavages at 16 medicinal-chemistry-relevant bonds; preserves rings, functional groups, bioisosteres | **Best** — bonds are exactly what med-chemists cleave when swapping bioisosteres while preserving target-binding; per-drug variable count (~5-15) | Some small molecules yield 1-2 fragments → need fallback |
| **RECAP** (`rdkit.Chem.Recap`) | Cleavages at 11 retrosynthetic bonds (amide, ester, ether, amine) | Simpler than BRICS; close to functional-group | Coarser, less ring coverage |
| **Murcko scaffold** (`rdkit.Chem.Scaffolds.MurckoScaffold`) | Single core ring system + linkers (one scaffold per drug) | Strong link to "chemotype / drug class" | Only 1 fragment per drug → cannot form a fragment **set** for hyperedge alignment |
| **MACCS / PubChem keys** | Fixed dictionary of substructures (166 / 881 bits) | Direct functional-group semantics, fast | Bag-of-bits, not a graph; MKG-FENN already does this — using = not novel |

→ **BRICS wins** on the alignment criterion. It produces a per-drug fragment **set** of meaningful size (3-10), each fragment is a chemistry-grounded interpretable unit, and the bonds it cleaves are exactly the moiety-swap boundaries used in pharmacology.

## E.3 Recommended pipeline (locked, BRICS primary + Murcko fallback)

```python
from rdkit import Chem
from rdkit.Chem import BRICS
from rdkit.Chem.Scaffolds import MurckoScaffold

MIN_FRAG_ATOMS = 3      # discard fragments < 3 heavy atoms
MAX_FRAGS = 12          # cap per drug; typical 3-10

def smiles_to_fragments(smiles: str) -> list[str]:
    mol = Chem.MolFromSmiles(smiles)
    if mol is None:
        return []
    # primary: BRICS retrosynthetic cleavage
    frags = list(BRICS.BRICSDecompose(
        mol,
        minFragmentSize=MIN_FRAG_ATOMS,
        returnMols=False,
        keepNonLeafNodes=False,
    ))
    # fallback for very small / non-decomposable molecules
    if len(frags) < 2:
        scaffold = MurckoScaffold.MurckoScaffoldSmiles(mol=mol, includeChirality=False)
        frags = [scaffold, smiles] if scaffold else [smiles]
    # dedupe, cap, strip BRICS dummy atoms "*"
    frags = list(dict.fromkeys(f.replace("*", "") for f in frags))[:MAX_FRAGS]
    return frags
```

**Hyperparameter rationale**:
- `minFragmentSize=3`: matches BRICS "brick" def (≥4 heavy atoms after stripping); removes methyl/halogen leaves
- `MAX_FRAGS=12`: empirical drug-side cap, matches typical 3-10 BRICS bricks
- `keepNonLeafNodes=False`: take terminal bricks only, avoids redundancy from composite fragments
- Murcko + whole-SMILES fallback: guarantees every drug yields ≥1 fragment node, required for alignment loss to be defined for all drugs
- Each fragment SMILES → existing molecular encoder (MPNN / Mol2vec / ChemBERTa) → fragment embedding → alignment to hyperedge embedding

## E.5 Connection to the v1.6.x framework

```
Drug SMILES
    ↓ (RDKit BRICS, Section E.3)
{fragment_i}_{i=1..N_d}   ← 3-10 chemistry-grounded fragments per drug
    ↓ (fragment encoder: MPNN / Mol2vec / ChemBERTa)
{e_frag_i}_{i=1..N_d}     ← fragment embeddings
    ↓ (cross-attention or contrastive alignment, C3 head)
align with {h_τ}_τ        ← KG hyperedge embeddings (12 anchor types)
    ↓
Joint pair representation z(a, b)
    ↓
DDI score
```

**Key claim**: this is the first multi-modal DDI architecture that does **chemistry-grounded fragment alignment with mechanism units** (HDN-DDI uses BRICS but only for hierarchical encoding, no KG alignment).
