# Insight 1

> **PK 对应分子，可直接使用 KG 的信息；PD 对应 effect，但需要语义感知。**

---

## 支撑实验

### 数据集

- 合并 KG：DrugBank + Hetionet + PrimeKG，178,029 节点 / 7,099,528 边
- ColdDDI seed=42，S2 split（G2 drugs，cold-start 未见过）
- PK / PD 标签：`ddi_pk_pd_labels.csv`（215 个 distinct ddi_type → 184 PD / 30 PK / 1 Mixed）
- LLM oracle：Claude Sonnet 4.5 (E8.2–E8.6, n=30/cl) + Claude Opus 4.6 selector × GPT-4o reasoner (E8.7-hetero, n=60/cl)

### 三层证据

**1. KG 拓扑层（E1b）**：PK / PD pair 共同 1-hop 中介的层级分布完全相反。

| 类 | 分子层 % | 效应层 % | mol/eff |
|---|---|---|---|
| PK | **83.2%** | 54.4% | 1.53 |
| PD | 64.7% | **75.8%** | 0.85 |

χ² p < 1e-300。

**2. GCN 性能层（E4）**：分子层对 PK 不可或缺，去掉 effect 不太伤 PD（因为 GCN 本来就没在用 effect）。

| KG variant | PK AUC | PD AUC |
|---|---|---|
| Full | 0.710 | 0.644 |
| Molecular-only | 0.697 (−1.2pt) | 0.640 (−0.4pt) |
| Effect-only | **0.590 (−12pt)** | 0.607 (−3.7pt) |

**3. LLM oracle 跨类 + 跨模型对比（E8.2 → E8.7-hetero）**：PD-effect 信号真实存在，bag pooling 抓不到；pair-conditional perception 解锁；信号跨模型稳定。

| 设计 | 模型 | n/cl | PD-effect AUROC | PK-effect AUROC |
|---|---|---|---|---|
| Single-stage bag + name (E8.2) | Sonnet 4.5 | 30 | 0.652 | 0.510 |
| Single-stage bag anonymized (E8.3) | Sonnet 4.5 | 30 | 0.686 | 0.510 (chance) |
| Pair-conditional + name (E8.6) | Sonnet 4.5 | 30 | 0.739 | 0.619 |
| **Pair-conditional, hetero (E8.7)** | **Opus 4.6 sel + GPT-4o reas** | **60** | **0.737** [0.65, 0.82] | **0.696** [0.61, 0.78] |

- **E8.3 匿名 single-stage**：cross-class gap **+17.6pt**，effect 信号 **PD 主导**的最干净证据
- **E8.6 vs E8.2**：pair-conditional 让 PD-effect 从 0.652 → 0.739（+8.7pt，paired bootstrap n=30, one-sided p=0.079）
- **E8.7 跨模型**：PD-effect 几乎不变（0.739 → 0.737）→ 不是单模型 artifact；PK-effect 上升到 0.696，可能反映 **PK-B 子类**（无 KG 介导实体那一半 PK，参 ColdDDI 论文）借到 effect 辅助 —— 但 n=60+模型变化叠加，不能单凭 E8.7 因果归因（需要按 PK-A / PK-B 分层验证）

E8.7 让 PD/PK cross-class gap 从 +12pt（E8.6）收窄到 +4.1pt。这**没有推翻**非对称性（PD 跨模型稳定且仍领先），但说明 i1 是 **primary-layer 非对称，不是 exclusive-layer**：
- "PK 对应分子" 应读作"PK 主要依赖分子机制"，不是"PK 完全只能从 KG 分子层解"
- PK-B 这种无 mediator 的 PK 子类临床上需要 effect 辅助，强 pair-conditional perception 能抠出这部分信号
- 方法启示：**对 mol 和 effect 都做 pair-conditional perception**，让 PK 主走 mol（含 PK-B 兜底 effect）、PD 主走 effect（含 PD-A 兜底 mol）

## 为什么分子（微观）能被 GNN 直接用，而效应（宏观）不行

> **核心**：分子层 KG 特征匹配局部关系聚合；效应层特征需要 pair-conditioned 语义组合。

这条非对称性不是偶然，是分子层和效应层信号在**证据单元**和**所需操作**上的结构性差异。

### 分子层信号 = instance-level 关系证据

- 两 drug 共享某个分子节点（enzyme、transporter、target）的事实本身就接近 PK 互作的因果基底
- 一对 drug 通过 "drug—CYP3A4—drug" 这样的 2-hop pair-pattern 直接被局部邻居聚合捕获
- 邻居各自提供局部、可解释的机制信号；GNN 邻域聚合（mean / sum / attention）是这种结构的自然算子
- DrugBank target/enzyme 标注密度高、噪声相对低，DDI 标签梯度能反传到具体酶/通路特征
- 但要注意：分子层 PK 机制不是纯加和——substrate-substrate、inhibitor-substrate、inducer-substrate 是方向性角色，role-dependent。GNN 通常没显式建模这层 directionality，但仍能从邻居共现里抽到大部分信号

### 效应层信号 = pair-conditioned 语义组合

- 单个 effect（如 "QT 延长"）本身**是有意义的临床风险因子**（不是 meaningless），但**不足以构成 DDI 信号**
- 大多数 PD-DDI 在 outcome 层面确实是加性的：QT + QT、bleeding + bleeding、CNS 抑制叠加
- 但模型必须先**找出哪一对 effect 可以 compose**：
  - drug A 的 QT 延长 + drug B 的 QT 延长 → 可加 ✓
  - drug A 的 QT 延长 + drug B 的便秘 → 不可加 ✗
- 难点不在"加和"，难点在"**从两 drug 各 ~20 个 effect 邻居里识别出那 1-2 个可 compose 的配对**"——这是 pair-aware semantic matching/selection 问题
- **标准 drug-embedding GNN pipeline**（独立聚合两 drug 邻域 → combine）天然吻合不上这个 selection：
  - 每个 drug 的邻域**独立**聚合，pair-level decision 出现在最后一步
  - 在 SE 邻居上 mean / sum / attention 把少数 composable effect 淹没在大量通用 SE 邻居里（per E1b 上下文：很多 SE 是 nausea / headache 这类通用毒性，多数 SE pair 不可加）
  - Attention 理论上能学稀疏选择，但 pair-label 监督到 node-level attention 的 credit assignment 是间接的；没有显式 pair-conditioned selection 机制时梯度信号又弱又含糊（这是 i3 的核心论断）
- 更具表达力的 GNN 变体（pair-GNN、cross-attention、edge-conditioned MP、subgraph-based）原则上可以近似 cross-product 推理；本论文论证的是 **当前主流 drug-embedding GNN 范式不适配**

### 两种聚合范式（架构层的归纳偏置差异）

| 维度 | 分子层 | 效应层 |
|---|---|---|
| 主要证据单元 | 局部分子关系 / 角色 | 临床可 compose 的 effect 对 |
| 适配操作 | 聚合机制相关邻居 | 选择并组合两 drug 的 effect |
| Pooling 风险 | 相对保留信号 | 稀有 composable effect 易被稀释 |
| Standard GNN 适配 | 强匹配 | 弱（除非显式 pair-conditioned）|

伪式表达（仅 conceptual，不 claim formal proof）：

- 分子层：`f(drug_a, drug_b) ≈ combine(pool(N(a)), pool(N(b)))` —— pair-decision 在最后
- 效应层：`f(drug_a, drug_b) ≈ select_compose(N(a) × N(b))` —— pair-aware selection 在前

### 对论文方法的启示

- 分子层证据走 standard GNN 邻域聚合就行（保留 backbone）
- 效应层证据需要新组件：让 drug A 和 drug B 的 effect 邻域**互相感知**，在 cross-product 空间上挑出 1-2 个 composable pair
- 这条路线被 E8.6 实验直接验证：相同 LLM、相同 30 个 PD-pos pair，仅把"bag → reasoner"换成"pair-conditional selector → reasoner"，PD-effect AUROC 从 0.652 → 0.739（+8.7pt）
- E4 中 GCN 在 PD-DDI 上的失败因此不是"数据无信号"，而是**聚合范式与信号结构不匹配**

## Caveats

- **i1 是 primary-layer 非对称**，不是 exclusive-layer。"PK 对应分子"读作"PK 主要靠分子"，"PD 对应 effect"读作"PD 主要靠 effect"。PK-B 子类和 PD-A 子类有跨层借信号的需求
- E8.6 paired Δ (PD effect, n=30): +0.087 [CI −0.034, +0.208]，one-sided p=0.079 marginal。E8.7-hetero (n=60) 把 PD CI 收紧到 [0.65, 0.82]，但跨模型设计本身的混杂使 PK 上升的因果归因不能仅靠 E8.7 单点
- PK-B 假设来自 ColdDDI 论文的 A/B 二分；E8.7 数据未按 PK-A/PK-B 分层，"PK 上升是 PK-B 借到 effect"是 consistent interpretation，非 proven causation
- PK/PD 标签来自 keyword-derived，未做 50-pair 人工 audit。E1b 路径分布的方向性结论不依赖标签精度，但 E8.x AUROC 的绝对值可能受影响
- 模型异构性已部分验证（Sonnet 4.5 / Opus 4.6 / GPT-4o 三个模型，PD 稳定）；更大规模跨模型 / 跨家族复现可加强结论
