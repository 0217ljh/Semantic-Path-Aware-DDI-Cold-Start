# Insight 4

> **节点名称的生物医学文本语义是 cold-start 下唯一不依赖训练 pair 曝光的稳定信号源。**

---

## 支撑实验

### 数据集

- 合并 KG：DrugBank + Hetionet + PrimeKG，178,029 节点 / 7,099,528 边
- ColdDDI seed=42，S2 split（G2 drugs，cold-start 未见过）
- LLM oracle：Sonnet 4.5 / Opus 4.6 + GPT-4o

### 三条腿的证据

**1. Feasibility（E1c · 节点名称可读率）**：i4 能否实施，先看 KG 节点的名称是否真有可用的文本。

| 节点类别 | n | Readable % |
|---|---|---|
| Drug (DrugBank) | 1,900 | **100%** |
| Side Effect (Hetionet) | 5,734 | 99.98% |
| gene/protein (PrimeKG) | 27,610 | 95.72% |
| Gene (Hetionet) | 20,945 | 92.05% |
| disease (PrimeKG) | 17,080 | 99.99% |
| effect/phenotype (PrimeKG) | 15,311 | 100% |
| 其它生物医学 kinds | — | 99-100% |
| Protein (DrugBank) | 2,482 | **0%** ← ID-only |
| Pathway (DrugBank) | 665 | **0%** ← ID-only |

整体可读率 **96.58%**。**100% drug 节点可读**——即 cold-start prediction target（每个 query drug pair）的两个 drug 都有可读名字，name-prior 在 cold-start 设定下永不缺失。

DrugBank Protein / Pathway 的 0% 是因为 DrugBank 用 ID 而 Hetionet / PrimeKG 用名字；这两类在合并 KG 里有 Hetionet/PrimeKG 的可读副本，**功能上可被替代**。

**2. 直接信号强度（E3 · init comparison + 多重 controls）**：

| Init | Random Proj | PCA Proj |
|---|---|---|
| Random Gaussian (128d) | 0.639 ± 0.005 | — |
| Type one-hot → projected | 0.686 ± 0.001 | — |
| Node2Vec (拓扑) | 0.654 ± 0.003 | — |
| **Real PubMedBERT [CLS]** | 0.654 ± 0.003 | **0.708 ± 0.002** |
| Shuffled-name PubMedBERT (同 kind 内打散) | 0.614 ± 0.004 | 0.654 ± 0.000 |
| Type-name only PubMedBERT (仅编码 kind 字符串) | 0.642 ± 0.001 | 0.672 ± 0.004 |

**Paired ΔAUROC (PCA projection)**：
- Real − Shuffled: **+5.65pt** [CI +5.30, +6.00] — CI 排除 0
- Real − Typename only: **+3.47pt** [CI +3.14, +3.81] — 具体名字 vs 仅类别名
- Real − Type onehot: **+2.64pt** [CI +2.30, +2.99] — 文本 vs 拓扑类别
- Real Random − Shuffled Random: +4.66pt [CI +4.35, +4.98] — 跨 projection 稳定

**关键 controls**：
- Random projection 和 PCA 两种投影下结果一致 → 不是 projection artifact
- Shuffled-within-kind 在同 kind 内打散名字 → 控制"语义 vs 容量"——real 比 shuffled 高 5.65pt 是 **specific name semantics 的贡献**
- Type-name only 编码仅 kind 字符串 → 控制"biomedical PT representation vs 具体节点名"——real 比 typename 高 3.47pt 是 **node-instance level semantics**

**3. 跨实验链证据（i4 在 i2 + i3 框架下的作用）**：

- E7 meeting-node LR (无 PubMedBERT) → AUROC 0.717 用 22 维手工特征
- 但 PubMedBERT init + 2-layer GCN → 0.708
- **两者持平**——说明 PubMedBERT 把"shared-mediator features"这部分手工 prior 在 init 阶段就编码进去了；模型可以直接 end-to-end 学
- E8.7-hetero 跨模型确认：Opus + GPT-4o pair-conditional perception 在 effect features 上达到 PD 0.737——与 E3 PubMedBERT GCN 同量级

## 为什么节点名 text 语义在 cold-start 下严格稳定

在 cold-start S2 设定下：
- **两 drug 都未训练时见过** → drug 节点的 learned embedding 是初始值（信息量极小）
- **训练时见过的 mediator 节点** → 学到 embedding
- **训练时未见过的 mediator 节点** → 初始值

i4 的 PubMedBERT init 在所有节点上都来自一个外部 pretrained 模型（不依赖 ColdDDI 训练数据）：
- 训练时见 / 未见的节点 init 同等 informative
- Drug 的 name "CYP3A4 inhibitor 类的 X" 即使 X 未在训练时出现，PubMedBERT 仍能从 name 字符串编出合理 vector

这是其它 init 方式没有的性质：
- Random init：随机，cold-start 完全无信号
- Node2Vec：依赖拓扑训练，cold-start 下 unseen drug 的 node2vec embedding 是默认值
- Learned ID embedding：cold-start 下 unseen drug 的 ID embedding 是初始值
- **PubMedBERT name embedding**：cold-start drug 的 name 是 known input → 永远有信号

## i4 的真实 novelty 定位

**这个 recipe 不是我们 invent 的**（per c7 paper review cluster）：
- KG-BERT (2019)、KEPLER (2021)、FuseLinker (2024)、BioMedKG (2025)、PrimeKG-CL (2025) 都用 entity-name encoder 作为 KG node init
- PubMedBERT / BiomedBERT 是社区共识的 biomedical encoder

**i4 的真正 novelty 是**：
1. **首次在 cold-start S2-DDI 上系统验证**：c7 这些方法都在 KG completion / drug repurposing / DTI 上 work，**没有任何一个在 S2-DDI cold-start 上验证过**——E3 是这个空白的第一个 controlled experiment
2. **与 i2 (meeting node) + i3 (pair-conditional perception) 联合**：c7 方法都直接用 PubMedBERT init 喂给标准 GNN；我们把它放在 meeting-node anchor + per-instance attention 框架下，构成完整方法
3. **跨模型 / 跨投影的稳定性验证**：E3 在 random / PCA 两种投影 + E8.7 跨 LLM 模型都看到相同的语义贡献——多 axis 独立验证不在 c7 之列

## Caveats

- DrugBank Protein / Pathway 节点 0% 可读 → 实际中要 fallback 到 kind 名编码（E1c 说明 1.81% 节点用 fallback）；这一 fallback 对 drug 节点和大多数 mediator 节点不影响
- PubMedBERT 的具体版本（base vs large）会影响绝对 AUROC，但不改方向；我们 E3 用 base
- 节点名 text 是 plausible / high-yield 的外部先验之一，**不是唯一**——SMILES embedding、ontology embedding 等其它 cold-start-stable source 也存在，但他们对应**不同 modality**，不直接竞争（SMILES 是 chemical structure，name 是 biomedical literature semantics）
- 与 i1 的耦合：i4 提供的 name vector 对 PK channel 和 PD channel 都 work（E3 没分 PK/PD 测）；具体 PK vs PD 上 name semantics 的差异需要单独 ablation
